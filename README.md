# Loco Acres Farm

Single-page website for Loco Acres Farm — Joe & Margie Kill's farm stand in Millbury, Ohio. Raw local honey; chicken, duck, turkey, and goose eggs; freezer meats (beef, turkey, chicken, rabbit); live poultry; and holiday birds by preorder.

- **Owners:** Joe & Margie Kill
- **Address:** 1760 Woodville Rd, Millbury, OH 43447
- **Phone:** 419-917-1706 · 419-349-2788
- **Hours:** Open daily, 10 am – 5 pm

## Structure

- `index.html` — the complete site (self-contained CSS, no build step; category photos hotlinked from Unsplash)
- `flock.webp` — real photo of the farm's young flock
- `screenshots/` — per-section screenshots of the rendered site

Open `index.html` in a browser, or deploy the folder as-is to any static host (GitHub Pages, Netlify, etc.).
